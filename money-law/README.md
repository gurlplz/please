# Money Law – Income & Banking Regulation Optimizer

**Income is a game derived from labor or capital.** This application maximizes the applicability of banking laws to your money management system.

## Concepts

- **Labor income**: Wages, salary, freelance, tips, contractor pay
- **Capital income**: Dividends, interest, rent, capital gains, royalties, business profits from invested capital

## Banking Laws Framework

| Law/Regulation | Applies To | Key Thresholds |
|----------------|------------|----------------|
| FDIC/NCUA | Deposits | $250k insurance per institution |
| BSA | Cash transactions | $10k+ reporting |
| TILA (Reg Z) | Consumer credit | Disclosure requirements |
| TISA (Reg DD) | Savings accounts | Fee/rate disclosures |
| EFTA | Electronic transfers | Consumer protections |

## Usage

```bash
pip install -r requirements.txt
python main.py
```
